# SalonLaRiviera
A simple and elegant website that showcases our event venue's offerings. Visitors can easily view venue details, explore event packages, and check space capacity for their special occasions.

# Features
Venue Information: Detailed descriptions and photos of the event space.
Package Details: Clear presentation of available event packages and pricing.
Capacity Information: Room specifications and guest capacity details.
Gallery: Photo showcase of the venue and past events.
Mobile Responsive: Easy viewing on all devices.
